# ARISE 1.3 — Fresh build

Independent starter project. ARISE 1.2 is not modified or included as the working base.

## Current stage
- New responsive dark-obisidian / glass shell
- Arabic RTL default with a language toggle
- Six module cards with distinct visual treatments
- No fabricated market values; data modules remain disconnected until sources are configured

## Files
- `index.html` — page structure
- `style.css` — visual system and responsive layout
- `app.js` — basic language toggle
- `favicon.svg`, `manifest.webmanifest` — app identity
- `.github/workflows/deploy.yml` — GitHub Pages deployment

## Deploy
Enable GitHub Pages using GitHub Actions, and push this folder's contents to a new repository named `ARISE1.3` (or any chosen repository name).
